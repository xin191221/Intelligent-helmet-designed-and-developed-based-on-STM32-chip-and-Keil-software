# Intelligent-helmet-designed-and-developed-based-on-STM32-chip-and-Keil-software
全球交通事故频发，非机动车骑行安全隐患突出，为提升骑行安全性，本文设计一款具备事故风险预警功能的智能头盔。系统采用感知层、视觉层、传输层、应用层四层架构设计，以STM32F103C8T6为主控芯片，通过 Keil5 完成程序开发与硬件电路调试。 感知层集成佩戴检测、温度检测、超声波测距、GPS 定位模块，实时采集数据并在 OLED 屏显示；视觉层基于 Open MV 实现后方来车智能识别，通过语音预警保障骑行安全；传输层采用 MQTT 协议，依托阿里云物联网平台实现数据上传与远程交互；应用层搭建可视化 UI 网页界面，支持在手机、平板等终端实时查看骑行状态。 经测试，头盔各模块功能稳定运行，可有效预警骑行风险，大幅提升非机动车出行的安全性与智能化水平。
